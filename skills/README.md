# Skills on demand

Skills for agents that are not loaded automatically. Each lives in `<name>/SKILL.md`, in the same
format as `claude-skills/`. Linked to `~/.skills`.

To use one, point the agent at it ("read ~/.skills/<name>/SKILL.md"), or link it into a
project's `.claude/skills/` to make it active there. Move it to `claude-skills/` to make it
active everywhere.
